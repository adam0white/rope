# The Rope

Lead five people up a mountain and back. Every one of them can say no.

A small browser game (installable, plays offline) built on the [Human Framework](https://github.com/adam0white/human-framework), a deterministic model of simulated people. Play it at https://rope.adamwhite.work.

```
npm install
npm run dev     # local game
npm run check   # lint, typecheck, tests
```
