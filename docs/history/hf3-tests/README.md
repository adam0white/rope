# Historical HF3 test source

These files preserve the pre-port tests from Rope's HF3 code on `c6bc6d4`.
They document old save admission, the HF3 internal Person layout and exact HF3 numerical outcomes.
They are text artifacts, outside the compiler and active test suite.

Current tests exercise HF4 public runs, complete current archives, exact current replay hashes,
public costed actions, retained v2 admission, explicit old-save refusal and shared season clocks.
HF3 saves and profile-only passports are refused. Their original files remain untouched.
The old three-climb outcome baseline is not a result measured on HF4.
